# gleaner-site

Public pages for **Gleaner** by **Spolora** (privacy policy for browser-store listings).

Kept separate from the private app repo so it can stay public on GitHub Free + GitHub Pages.

## Live URL

After Pages is enabled:

```text
https://spolora.github.io/gleaner-site/
```

Use that as the Privacy Policy link in Chrome / Edge / Firefox store listings.

## Contact

Privacy questions: [GitHub Issues](https://github.com/Spolora/gleaner-site/issues)

## Local preview

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```
